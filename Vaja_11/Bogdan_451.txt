Build a simple, clean, and cheerful birthday countdown web app.

Technical Stack, Constraints & Architecture:
- Build with React + TypeScript, Vite, and Tailwind CSS v4. Show proper TypeScript types and strictly avoid `any`.
- Do NOT install any additional packages or icon/animation libraries (use native CSS animations and standard emojis).
- Architect the application into five distinct files/components:
  1. `App.tsx`: Manages the application state (loaded/saved from/to `localStorage` on render/updates), and orchestrates the layout.
  2. `BirthdayHero.tsx`: Receives countdown data via props and displays the main visual highlight.
  3. `BirthdayForm.tsx`: Handles input and edit workflows, passing submit/cancel events back up.
  4. `BirthdayList.tsx`: Receives sorted items via props and renders the collection.
  5. `BirthdayCard.tsx`: Individual visual card displaying individual countdowns, age metadata, and actions (edit/delete).
- State and Timer Management: Manage state with `useState`. For the countdown ticking, implement a `useEffect` that triggers `setInterval` to update the time remaining, with proper dependencies and a returned cleanup function (`clearInterval`) on unmount to prevent double ticking. Pass data and handlers to sub-components through explicit TypeScript `props`.

Requirements:
1. Main Hero Countdown (at the top): Display a live, ticking countdown in days, hours, minutes, and seconds (`DDd HHh MMm SSs` in a tabular-num/monospace font so digits do not shift) to the nearest upcoming birthday, along with that person's name and emoji. If there are no birthdays saved yet, show a clean empty state prompting the user to add one.
2. Today's Birthday Banner (edge case): When someone's birthday is today, replace or highlight their card at the top with a celebratory "Happy birthday!" banner featuring a subtle, pure-CSS animation, and do not count them down to next year until tomorrow.
3. Add & Edit Form (inline or collapsible section below the hero, NOT in a modal): Allow adding and editing a person with the following data model: `id` (string), `name` (required string), `day` (number 1–31), `month` (number 1–12), `year` (optional number), and `emoji` (optional string, defaulting to 🎂 if left blank).
4. Sorted Birthday List (at the bottom): Display all saved birthdays sorted chronologically by next upcoming occurrence, showing the person's emoji, name, formatted birth date, days remaining, and the age they will turn (only shown if `year` is provided). Include Edit and Delete buttons on each item with a minimum touch target of 44x44px.
5. Date & Leap Year Calculation: If a birthday has already passed in the current calendar year, calculate the countdown to the following year. If a person's birth date is February 29, celebrate and count down to February 28 in non-leap years.
6. Local Storage Persistence: Automatically load saved entries from `localStorage` on initial render and save any additions, edits, or deletions immediately.

Aesthetics & Design (Cute, not overloaded):
- Palette: Soft pastel cream (`#fdfbf7`) or pastel peach (`#fff5f0`) for the background, with a single accent color (`#f6c90f`) used consistently for primary buttons and highlights.
- Styling: Use rounded corners (`rounded-2xl` or `rounded-3xl`) and at most `shadow-md` on cards.
- Layout & Detail: Center the layout vertically on the screen with a width of 400–500px, targeting mobile-friendly touch sizes (minimum 44x44px for interactive elements). Use fixed-width numeric typography (`tabular-nums`) for the countdown digits. Include a single cute detail—one cake emoji (`🎂`) next to the app title—and keep the interface cute, not overloaded.

Keep the code clean and readable — this will be used to teach React fundamentals, so prefer clarity over cleverness.
