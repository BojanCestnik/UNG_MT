Build a cute and modern daily planner app called "Moj Ritem" 
Create a beautiful, modern and user-friendly daily planning application called Moj Ritem.
The application helps users organize their everyday lives, plan daily activities, set personal goals, manage events and receive reminders about upcoming obligations.
The main goal is to help users create a balanced daily routine, stay organized and make time for the things that matter.

•	Display daily task completion progress.
•	Highlight upcoming events and reminders.
2. Daily Tasks
•	Add, edit and delete tasks.
•	Set task titles, descriptions, dates and times.
•	Mark tasks as completed.
•	Organize tasks into categories.
•	Highlight important and overdue tasks.
3. Personal Goals

6. Statistics and Progress

The final application should feel like a personal daily assistant that helps users find their own rhythm and organize everyday life.

STEP 4 — Code Architecture, State and Data Flow
Build Moj Ritem with exactly five main React components, each in its own clearly named file. Do not put all code into one component or one file:
1. App.tsx — the root component and single source of truth. Store tasks, calendar events, personal goals, reminder settings and the active screen with useState. Render the six Slovenian navigation options (Domov, Moje naloge, Koledar, Moji cilji, Statistika, Nastavitve). Render the simple Settings form directly here, and pass typed data and callbacks to the other components.
2. DashboardView.tsx — display a friendly welcome, today’s date, today’s tasks, upcoming events, reminders and daily progress. Accept a typed mode prop ("home" or "statistics"); in statistics mode, show completed vs. unfinished tasks, daily/weekly productivity and goal progress calculated from shared data.
3. TasksView.tsx — list, add, edit, delete, categorize and complete tasks. Accept tasks via props and call parent callbacks for updates. Highlight important and overdue unfinished tasks; show a friendly empty state when no tasks exist.
4. CalendarView.tsx — provide working daily, weekly and monthly calendar views. Display events in chronological order with category colors, and allow the user to add, edit and delete events through typed callbacks.
5. GoalsView.tsx — add, edit and complete daily, weekly and monthly goals, set deadlines, update progress and display progress bars and completion percentages. Receive all goal data and update callbacks through typed props.
Define explicit TypeScript types or interfaces in a shared types.ts file: Task { id, title, description, date, time, category, important, completed }, CalendarEvent { id, title, date, time, category, reminderMinutesBefore }, Goal { id, title, period, deadline, target, progress, completed }, and AppSettings { remindersEnabled, defaultReminderMinutes }. Use string IDs, ISO-style local dates (YYYY-MM-DD), 24-hour times (HH:mm), booleans and appropriate number/union types. Do not use any or untyped props.
Keep shared data in App using useState; pass data down via props and changes upward via callbacks. Derive progress and statistics from that state instead of storing duplicate values. Use functional state updates where the next value depends on the previous value.
Initialize the app with a few realistic sample tasks, events and goals. Safely load saved data from localStorage when available, and use useEffect to persist changes. Handle invalid stored data by falling back to sample data without crashing.
Use useEffect for any time-based reminders: check at a sensible interval (such as once per minute), clear the interval on unmount, and prevent duplicate reminders. Reminders should be in-app notifications while the application is open; do not pretend to provide background or push notifications. Keep effect dependencies correct and clean up subscriptions or intervals.
Make edge cases explicit: no tasks means 0% progress (not NaN); overdue means an unfinished task with a past due date; an empty calendar or goal list shows a helpful message; and editing or deleting an item immediately updates all relevant screens. Avoid automatic changes the user did not request.
STEP 5 — Precise, Consistent Visual Design
Use Tailwind CSS v4 only, with a cute, calming and minimalist pastel style. Follow these concrete design rules rather than interpreting "make it beautiful" freely:
•  Background: #F8F7FF (very pale lavender); cards and input surfaces: #FFFFFF. Use light blue #DDF1FF and pale lavender #E9E4FF only as soft supporting accents. Use #6D5CE7 as the one strong accent for primary buttons, active navigation and progress highlights.
•  Primary text: #25243A; muted text: #66657A. Ensure readable contrast and use one consistent font family across screens.
•  Use rounded-2xl or rounded-3xl for cards and forms, gentle shadow-md at most, and subtle hover/transition effects. Avoid large gradients, excessive shadows, animations or visual clutter.
•  Use a consistent spacing scale of 8, 12, 16, 24 and 32 px. Center the main app content and cap desktop content width at about 1120 px. Keep forms and dialog panels at a maximum of about 480 px.
•  Make the layout responsive for a 360–430 px mobile screen, tablet and desktop. On mobile use 16 px side padding, legible text of at least 16 px for input fields, and touch targets of at least 44 × 44 px. Do not allow horizontal scrolling or clipped controls.
•  Use tabular-nums for progress percentages, dates and numeric summaries so numbers do not visually jump when values change. Keep icons consistent and small; show a subtle flower detail near the Moj Ritem title rather than repeating decorations everywhere.
•  Use clear Slovenian labels, accessible focus states and simple layouts. Every calendar category may have its own gentle pastel marker, while actions and selected states continue using the same primary lavender accent.
STEP 6 — Purpose, Code Quality and Success Criteria
Keep the code clean and readable — this will be used to teach React fundamentals, so prefer clarity over cleverness.
Moj Ritem is intended for Slovenian-speaking people, especially students and young adults, who want a simple, calming personal organizer. The goal is not to add as many features as possible; it is to make daily planning quick, reassuring, understandable and easy to maintain.
Success means that the user can navigate all six sections, create/edit/delete tasks and events, track goals, see accurate statistics, change reminder settings, and retain their data after refreshing the page. All visible controls must work; no placeholder buttons or fake features. Keep the interface in friendly, natural Slovenian.
Prioritize accessibility, responsive behavior, clear variable names, small understandable functions, reusable typed props and easy future upgrades. Avoid unnecessary abstractions and additional packages. Use only React, TypeScript, Vite, Tailwind CSS v4 and the browser APIs already available in the environment. Deliver a complete, runnable frontend with sample data; no backend is required.
