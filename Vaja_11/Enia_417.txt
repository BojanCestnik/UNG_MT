HTML5
JavaScript (ES6)

Restrictions:
No React
No external libraries
No Bootstrap
No database

Adding Tasks:
Task title
Subject
Exam
Assignment
Project
Due date
List Display

Title
Subject
Type
Due date
Status
Marking as Completed

Completed tasks should have:
Strikethrough text
Green indicator
Reduced emphasis
Deleting Tasks

Filtering:
All
Active
Completed
