# Where's the Party
React + TypeScript + Vite + Tailwind CSS v4.

Run `npm install`, then `npm run dev`. Open the URL printed by Vite. Run `npm run build` to type-check and build.

All venues, addresses and events are fictional. Crowd reports use the latest local report and persist on the same browser; no cross-device sync. The map is schematic.

Manual test checklist: search by name; combine genre and crowd filters; sort Packed first; favourite a venue and reload; report a crowd level and verify count/time after reload; open Tonight and Map; select a map pin; check narrow mobile layout and no-results message.
