NOTEBOOK — STUDY PLANNER

Project files:
- index.html: page structure and task form
- style.css: visual design, colors, layout and responsive styles
- script.js: add, display, filter, complete, delete and save tasks

How to run:
1. Extract the ZIP archive.
2. Open index.html in a modern web browser.

No React, external libraries, Bootstrap, server or database are required.
Tasks are saved in localStorage in the browser on this device.
