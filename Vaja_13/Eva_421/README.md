# Odštevalnik (React.js)

Sodobna in pregledna aplikacija za odštevanje dni do dogodkov ter izračun razlike med dvema datumoma.

## Zagon projekta

1. Razširite arhiv v delovno mapo.
2. Odprite terminal v mapi projekta in namestite odvisnosti:
   ```bash
   npm install
   ```
3. Zaženite razvojni strežnik:
   ```bash
   npm run dev
   ```
